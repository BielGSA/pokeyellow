# Pokemon Yellow Complete - Project Status

Final working source package.

Implemented custom features include:
- Existing 37-map wild encounter redistribution retained as requested.
- Kadabra -> Alakazam at Lv. 42.
- Haunter -> Gengar at Lv. 42.
- Machoke -> Machamp at Lv. 45.
- Graveler -> Golem at Lv. 45.
- Gym Leader rematches.
- Elite Four / Champion rematches.
- Mew special encounter already present in the project.
- Post-Champion Indigo Plateau shop adds Master Ball and Rare Candy for $10 each.
- Repel reuse prompt: if another Repel of the same type is in the Bag, the game asks whether to use another.
- Brock rematch reward: after defeating Brock in the post-game rematch, he gives whichever Mt. Moon fossil the player did not choose. The reward is only given once; if the Bag is full, it can be obtained on a later victory.

Note: source changes require RGBDS to rebuild the .gbc ROM.
